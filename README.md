# M&G NatureWorks International Research Institute

Static website built with HTML, CSS and JavaScript. No package install or build step is required; Vercel serves `index.html` from the repository root.

## Project structure
- `index.html` — page markup
- `css/styles.css` — styling and responsive layouts
- `js/` — interactions, frame sequences, gallery and product cards
- `assets/images/` — logo, product and community imagery
- `assets/frames/` — optimized JPG sequences used by the scroll animations

## Run locally
Run `python3 -m http.server 8000` from the repository root and open `http://localhost:8000`.

## Before public launch
- Replace demo testimonials and profiles with genuine, consented testimonials.
- Verify all historical dates, founder biographies and product descriptions.
- Obtain regulatory/legal review for health or treatment claims; do not present products as proven cures without appropriate evidence and authorization.
- Confirm contact details, WhatsApp destination and form behavior.
- Replace generated-looking portraits/product imagery with approved real assets where available.

The original source-video files are excluded from the deployed repository; the JPG frame sequences are retained.
